# Натальная карта — версия для телефона

Собранная версия приложения для GitHub Pages. Исходный код и история — в приватном репозитории `natal-chart`;
этот репозиторий пересобирается командой `python tools/build_site.py <путь к этому репозиторию>`.

Карты хранятся только на телефоне (localStorage браузера). Резервная копия: Настройки → «Резервная копия».
